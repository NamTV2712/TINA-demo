# src-tauri — the native desktop shell

Rust/Tauri host for the native Desktop client. It owns the parts a webview cannot: audio capture and
echo cancellation, the always-on-top overlay and subtitle windows, the global Fn key, and the signed
WebSocket that streams captured audio to meeting-api.

- `src/` — the Rust crate
- `capabilities/` — the Tauri ACL grants the windows run under
- `ui/` — the webview front end this shell loads
- `icons/` — bundle artwork
- `gen/` — regenerated by `tauri build`; not source

`Cargo.lock` stays in the tree: the shipped binary is what CI and release builds compile.
