# extension/assets — static extension assets

Copied verbatim into `dist/` by `build.mjs`. Referenced by the viewer manifest
and side-panel HTML.

- `tina-light.svg` / `tina-dark.svg` — the TINA mark, light- and dark-theme variants.
- `icons/` — toolbar PNGs rendered from `branding/favicon.svg` at 16, 32, 48 and 128 px.
- The extension build also copies `branding/tokens.css` into `dist/assets/` for the viewer theme.
