# Branding icons

UI glyphs used by the Terminal and Desktop surfaces (`accept`, `reject`, `deadline`, `microphone`,
`microphone-off`, `participants`, `review`). Each is a standalone SVG so a surface can inline it.
`preview.html` renders the whole set at native and double size.

Logo lockups and wordmarks live in [../logos/](../logos/); the kit overview is [../README.md](../README.md).
