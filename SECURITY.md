# Security policy

TINA is currently a local self-hosted project. Its Git remote and private vulnerability-reporting
channel have not been configured.

Do not publish vulnerability details in a public issue or discussion. Contact the person who
provided this TINA checkout through a private channel and agree on a disclosure plan before sharing
reproduction steps or sensitive data.

The project has not set a response-time commitment or a supported-version policy yet. Run the stack
only on infrastructure you control and keep credentials out of logs and source files.
