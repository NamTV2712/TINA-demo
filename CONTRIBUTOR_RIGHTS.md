# Contributor rights

TINA source is distributed under Apache-2.0. Before submitting changes, confirm that you have the
right to provide them under that license and preserve existing copyright and attribution notices.

## Rights paths

- **Independent:** you created the contribution or otherwise control the right to submit it.
- **Corporate:** an employer, client, or other entity may control the contribution. This checkout
  has no verifier or corporate authorization contact configured, so this path cannot currently be
  approved.
- **Uncertain:** request a private review before merging. No TINA review contact is configured yet.

The local PR rights workflow also waits for a `DCO` check from the GitHub DCO App. Before using it
on a GitHub repository, install that app and configure the rights policy. Never add a sign-off for
another person or rewrite shared Git history without the affected contributors' agreement.
