# TINA governance docs

This section describes architecture and local development practice for the self-hosted TINA
checkout. No public TINA Git remote, issue tracker, support channel, or release registry is
configured yet.

The root `AGENTS.md`, `CONTRIBUTING.md`, `CONTRIBUTOR_RIGHTS.md`, and `SECURITY.md` are the local
repository policies. Preserve Apache-2.0 and third-party attribution notices when changing code.
