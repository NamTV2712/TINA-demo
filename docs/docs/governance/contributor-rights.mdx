---
title: "Contributor rights"
description: "Current contribution-rights policy for the local TINA checkout."
---

TINA source is distributed under Apache-2.0. Contributors must have permission to submit their
changes under that license and preserve existing copyright and third-party notices.

This checkout has no Git remote, DCO verification service, or corporate authorization contact
configured. The local PR rights workflow waits for a `DCO` check from the GitHub DCO App; install
that app and configure the rights policy before using the workflow on a GitHub repository. If an
employer or client controls the work, obtain written authorization before submitting it. Never sign
for another person or rewrite shared history without the affected contributors' agreement.
